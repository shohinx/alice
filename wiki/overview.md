# Overview

This knowledge base uses a three-layer structure inspired by the LLM Wiki pattern.

## Structure

- `raw/` stores immutable source material.
- `wiki/` stores maintained synthesis pages.
- `outputs/` stores derived artifacts such as reports, slides, and figures.

## How To Use It

- Add new source material to `raw/`.
- Maintain the synthesis in `wiki/`.
- Write durable answers and analyses back into the wiki instead of leaving them only in chat.
- Keep `wiki/index.md` and `wiki/log.md` updated as the repository evolves.
